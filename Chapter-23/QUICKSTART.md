# Chapter-23 Quickstart

## Option 1: Google Colab (Recommended)
Click any **Open in Colab** badge in [`README.md`](README.md) or Cell 1 of a notebook, then run cells top-to-bottom (`Runtime -> Run all` after completing `# TODO` blocks).

## Option 2: Local JupyterLab / VS Code
```bash
pip install -r ../requirements.txt
jupyter lab
```
Complete each `# TODO` block (replacing `raise NotImplementedError("Complete this TODO")`), then run the self-check `assert` cell at the bottom of each notebook.
