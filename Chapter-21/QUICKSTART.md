# Chapter 21 Quickstart

1. Open any notebook via its **Open in Colab** badge or locally in JupyterLab / VS Code.
2. Only `numpy` and the Python standard library are required.
3. Replace each `# TODO` and `raise NotImplementedError("Complete this TODO")` with your implementation.
4. Run all cells top-to-bottom and confirm the `assert` self-checks pass.
