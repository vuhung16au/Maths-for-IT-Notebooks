# Quickstart — Chapter-10: More Linear Algebra

## Option 1: Google Colab (Recommended)
Click any **Open in Colab** badge in [`README.md`](README.md) or at the top of a `.ipynb` file. No local installation is required; only Python 3.10+ standard library and `numpy` are used.

## Option 2: Local Jupyter / VS Code
```bash
cd 09.Maths-for-IT-Notebooks/Chapter-10
jupyter lab
```

## Notebooks in This Chapter
- `01-cosine-similarity-and-ranking.ipynb` — Cosine similarity and ranking candidate embeddings against a query
- `02-vector-projection-gram-schmidt.ipynb` — Orthogonal projection and Gram–Schmidt orthonormalisation
- `03-linear-independence-and-rank.ipynb` — Linear independence, collinearity detection, and rank classification
- `04-least-squares-line-fitting.ipynb` — Least-squares line fitting via normal equations and `np.linalg.lstsq`

## Self-Check Workflow
Each notebook ends with a self-check cell containing `assert` statements aligned with the textbook worked examples. Before you implement the `# TODO` blocks, running the notebook raises `NotImplementedError`. Once complete, all cells should execute in under 5 seconds with zero errors.
