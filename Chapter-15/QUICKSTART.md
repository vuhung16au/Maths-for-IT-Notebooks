# Chapter 15 Quickstart

1. Open any notebook in Google Colab using the badge in `README.md` (or run locally in JupyterLab / VS Code with Python 3.10+ and `numpy`).
2. Read the mathematical context and worked-example references.
3. Replace `# TODO: ...` and `raise NotImplementedError("Complete this TODO")` with your implementation.
4. Run the self-check assertion cell to verify your solution.
